# Siddha365 codebase guide

The active website is generated by `build_site.py`. Edit the source files below, then run the build. The root page folders and `dist/` are generated outputs; avoid editing them directly.

| What to find or change | Source |
| --- | --- |
| Clinic phone, social links, maps, review feed, logo and doctor image paths | `site_content.py`, top section |
| Treatment card text, individual care-guide text, sources and image choice | `site_content.py`, `CONDITIONS` |
| Main navigation and homepage slider images | `site_content.py`, `NAV` and `HOME_SLIDES` |
| Homepage care topics and YouTube/Instagram media | `site_content.py`, `SPECIALTY_CARE`, `VIDEOS`, `POPULAR_VIDEOS`, `YOUTUBE_SHORTS`, and `INSTAGRAM_REELS` |
| Partner logos | `site_content.py`, `PARTNER_LOGOS` |
| Page templates, links, asset paths, and generated routes | `build_site.py` |
| Base layout and component styles | `assets/site.css` |
| Later layout refinements and responsive fixes | `assets/refinement.css` |
| Final experience styles and motion behavior | `assets/experience.css` |
| Browser interactions | `assets/site.js`, `assets/experience.js`, and `assets/reviews.js` |
| Local preview server | `preview_site.py` |

The stylesheets load in this order: `site.css`, `refinement.css`, then `experience.css`. Later rules may override earlier ones, so check all three before changing a layout rule.

Each entry in `CONDITIONS` has a `slug` for its route, card fields such as `title`, `category`, and `image`, and care-guide fields such as `intro`, `why`, `care`, `safety`, and `sources`. The build uses this one list to make the Treatments index, individual treatment pages, and related-care cards.

Run `.venv\Scripts\python.exe build_site.py` from this folder after editing source content or styles. It regenerates the root page folders and the deployable `dist/` folder. Some assets referenced by the generated site live in the existing `assets/` and `wp-content/` folders. The other `wp-*` files and old `index*.html` files belong to the original site mirror; they are not the page templates for the generated site.
